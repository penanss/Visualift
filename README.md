# Product Requirements Document: Penans

## Overview

**Product Name:** Penans  
**Problem Statement:** Penans helps designers and students turn hard-to-describe visual inspiration into usable image prompts faster than manual searching.  
**MVP Goal:** Create a personal desktop-first tool that takes a reference image, builds an enhanced prompt, lets the user review/edit it, then generates 3 visual options for inspiration and selection.  
**Target Launch:** 1–3 months

## Target Users

### Primary User Profile
**Who:** Designers, graphic designers, and design students  
**Problem:** They spend too much time manually searching for the right image inspiration for a project  
**Current Solution:** Manual browsing and searching with no structured tool  
**Why They'll Switch:** Penans turns a reference image into a clearer prompt and faster image options, reducing time and guesswork
